# Changelog

## 0.1.1

- GPU temperature next to each adapter name and disk temperature next to each drive letter on Windows, read without administrator rights. Hard disks are only asked while busy, so they can still spin down. GPU temperature for NVIDIA cards on macOS and Linux.
- The footer temperature is now labeled CPU temperature.

## 0.1.0

- First release: sidebar view with live CPU, memory, GPU, disk and network graphs, drive usage, battery, CPU temperature and uptime.
- `systemMetrics.showCores` setting to show a usage bar per CPU core.
